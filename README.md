# Punith B — Portfolio

Built with Next.js 16, TypeScript, Tailwind CSS v4, Framer Motion and Lenis.

## Run locally

```bash
npm install
npm run dev      # http://localhost:3000
```

## Edit content

All text, projects, skills, education and links live in `src/data/portfolio.ts`.
Replace `public/Punith_B_Resume.pdf` to update the downloadable résumé.

## Deploy (free)

1. Push this folder to a GitHub repo.
2. Go to https://vercel.com/new, import the repo, and click **Deploy** (no settings needed).
